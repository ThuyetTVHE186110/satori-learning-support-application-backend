description: Debug API issues in Spring Boot backend.

---

Instructions:
1. Identify endpoint and request
2. Compare expected vs actual result
3. Check Controller input handling
4. Trace Service logic
5. Check:
    - Validation
    - Business logic
    - Repository calls
    - Redis cache
    - External APIs
6. Identify root cause
7. Suggest fix

Output:
- Root cause
- Where failure occurs
- Suggested fix
